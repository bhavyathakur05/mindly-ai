   # Mindly AI
   A ChatGPT-style chat app with streaming responses, built with Next.js, React, TypeScript, Tailwind CSS and the Google Gemini API.

   ## Features
   - Live streaming replies with a Stop button
   - Sidebar with search, rename and delete
   - Markdown and syntax-highlighted code
   - Image attachments, model tiers, light/dark themes

   ## Setup
   1. `npm install`
   2. Copy `.env.example` to `.env.local` and add your Gemini API key
   3. `npm run dev`
   4. Open http://localhost:3000
